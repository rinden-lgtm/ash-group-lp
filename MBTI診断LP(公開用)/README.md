# ASH MBTI Training LP

ASH新入社員研修向けのMBTI診断LPです。

## Deploy

Vercelで静的サイトとしてデプロイします。

- Vercel project name: `ash-group-lp`
- Domain: `mbti-up.store-ash.jp`
- Root directory: `MBTI診断LP(公開用)`
- Build command: なし
- Output directory: なし
- Install command: なし

`index.html` を公開ルートに配置しているため、GitHub連携後はこのフォルダをRoot Directoryに設定すれば公開できます。
